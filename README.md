# Тестовое задание для стажёра Backend-направления (весенняя волна 2025) Avito

## Запуск проекта

Файлы с переменными окружения находятся в репозитории для простоты в демонстрационных целях.

Запуск:

```shell
$ docker compose up
```

Для аутентификации можно создать пользователя через _/register_, получить токен через _/login_, а затем указать полученный токен в header'е _Authorization_ в формате "Bearer <токен>". Также для получение токена без регистрации пользователя существует endpoint _/dummyLogin_.

## Дополнительная информация

Юнит-тесты бизнес-логики находятся рядом с самими сервисами _./internal/services/_

Интеграционный тест находится по пути _./tests/integration/_
